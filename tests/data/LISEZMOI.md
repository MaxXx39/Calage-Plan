# Fichiers de test (non versionnés)

Les plans réels sont confidentiels : ils ne sont pas publiés dans le dépôt.
Pour lancer les tests, déposer ici :

- `plan_A.dwg`   — plan d'ingénieur d'origine (indice A, en cm)
- `final_A.dxf`  — résultat calé et nettoyé à la main (MN95, m)
- `reference.dwg` — fond du géomètre officiel (MN95)

Sans ces fichiers, les tests correspondants sont ignorés (« skipped »).
